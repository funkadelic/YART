The basic database is free to use, including commercially, and requires
attribution to simplemaps.com as the source. The upstream license document
ships alongside this file as license.pdf.

The initial cities.json was formatted by scripts/generate-cities.mjs from the row data already committed to this repository, not from a fresh CSV run.
Later revisions are regenerated by that script from the upstream worldcities.csv export, which orders rows by descending population and breaks ties by ascending id, so a regenerated file is not expected to be byte-identical to this one.
Only the fields the City type needs are kept: id, name, nameAscii, country,
countryIso3, capital, population. The lat, lng, iso2, and admin_name columns
are dropped. Rows are ordered by descending population, so the default view
leads with the largest cities.
